
# Engineering Guides

A growing collection of interactive resources for engineering students and practicing engineers.

## What This Project Includes

- Formula quizzes

- Engineering cheatsheets

- Interactive applets

- Calculators

- Visual learning tools

- General study resources

## Current Resources

- Engineering Geometry Formula Quiz

## Goal

The goal of Engineering Guides is to make common engineering concepts easier to review, practice, and understand through simple browser-based tools.
